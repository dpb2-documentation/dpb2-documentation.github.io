What is DPB2?

DreamPoeBot 2 (DPB2) is an automation framework for Path of Exile 2, built on .NET 8 and WPF. If you've worked with the original Exilebuddy, the API will feel familiar: almost everything lives under the DreamPoeBot.Loki.* namespaces. DPB2 reads the game state straight from client memory (entities, health, the navmesh, the UI panels) and hands you that data through a broad API, so you can write your own bots and behaviours as precompiled .NET plugins.

Unofficial, community-maintained

This site explains how the DPB2 plugin system works, written by members for members. It isn't an official publication, so when something really matters, check it against the bundled DreamPoeBot.xml and the live DLL metadata.

DPB2 at a glance

ConceptWhat it is
Runtime.NET 8 (WPF desktop app). Plugins target net8.0-windows.
NamespacesCore API under DreamPoeBot.Loki.* (such as Loki.Game, Loki.Bot, Loki.Game.Objects).
PluginsPrecompiled .dll files. DPB loads every type implementing IBase.
Entry pointLokiPoe, the static gateway to all game state and input.
LoopTick() runs every ~30 ms; actions run inside coroutines, not in Tick.

Plugin types you can build

DPB2 discovers and loads any type that implements one of these top-level interfaces:

InterfaceRole
IBotA full bot, owns the task loop and decides what the character does.
IRoutineA pluggable combat/skill routine, invoked by bots via RoutineManager.
IPlayerMoverMovement strategy (click-to-move, WASD…) used through PlayerMoverManager.
IPluginA general add-on with its own settings UI, lifecycle and logic hook.
IContentContent provider managed by ContentManager.
